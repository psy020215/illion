# 이리온 코리아 홈페이지

GitHub Pages로 운영하는 (주)이리온 코리아 홈페이지입니다.
**내용은 `content` 폴더의 파일 3개만 고치면 됩니다.** 저장(Commit)하면 1~2분 뒤 사이트에 반영돼요.

| 고칠 내용 | 파일 |
|---|---|
| 회사 정보(주소·전화·이메일), 메인 문구, 회사 소개, 연혁, 제품 분류 | `content/site.yml` |
| 취급 원료(제품) 목록 | `content/products.csv` |
| 공지사항 | `content/notices.md` |

## 1. 회사 정보·소개 문구 고치기 (`site.yml`)
1. GitHub에서 `content/site.yml` 클릭 → 오른쪽 위 연필 아이콘
2. `:` 뒤의 글자만 바꿔요. 앞의 들여쓰기(공백)는 그대로 두세요.
3. **Commit changes**

연혁 추가 예시 (`history:` 아래, 최신순):
```yaml
  history:
    - year: 2026
      text: 홈페이지 리뉴얼
    - year: 2018
      text: (주)이리온 코리아 설립
```

## 2. 제품 목록 고치기 (`products.csv`)
**방법 A — 엑셀/Numbers로 (추천)**
1. `content/products.csv`를 열고 오른쪽 위 다운로드 버튼으로 받아요.
2. 엑셀이나 Numbers로 열어 행을 추가·수정·삭제해요. 첫 줄(제조원, 상품명, INCI, 효능)은 그대로 두세요.
3. 같은 이름(`products.csv`)으로 저장해요. 엑셀은 **CSV UTF-8** 형식을 권장하지만, 일반 CSV로 저장해도 한글이 깨지지 않게 처리돼 있어요.
4. GitHub에서 `content` 폴더로 들어가 **Add file → Upload files**로 덮어 올리고 Commit.

**방법 B — GitHub에서 바로**
연필 아이콘으로 열고 한 줄을 추가해요. 쉼표가 들어간 칸은 큰따옴표로 감싸요.
```
ILION KOREA,새 원료 이름,"Water, Glycerin",보습
```

- 효능이 여러 개면 쉼표로 구분해요(예: `보습, 장벽강화`).
- 제조원을 `ILION KOREA`로 쓰면 메인의 "자체 원료"에 자동으로 나와요.
- 메인의 원료 수, 제조사 수, 분류별 개수는 이 파일에서 자동으로 계산돼요.

## 3. 공지사항 쓰기 (`notices.md`)
연필 아이콘으로 열고 **맨 위 공지 위에** 이렇게 추가해요.
```
## 2026-12-01 | 공지 제목
본문을 씁니다.
```
- `## 날짜 | 제목` 줄이 공지 하나의 시작이에요. 날짜는 `YYYY-MM-DD` 형식이에요.
- 최신 3개는 메인 화면에도 자동으로 나와요.

## 4. 그 밖의 것
- 메인 오른쪽 그림: `assets/hero-network.jpg` (같은 이름으로 바꿔 올리면 교체)
- 디자인: `assets/css/style.css`
- 문의 폼은 방문자의 메일 프로그램을 열어 `site.yml`의 이메일 주소로 보내는 방식이에요.

## 문제가 생기면
- 화면에 "내용 파일을 불러오지 못했어요"가 나오면, 방금 고친 파일의 형식(들여쓰기, 쉼표, 따옴표)을 확인하세요.
- 저장소의 **History**에서 이전 버전으로 되돌릴 수 있어요.
